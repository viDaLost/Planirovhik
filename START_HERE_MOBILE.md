# Начните здесь: публикация с телефона

Проект уже подготовлен к автоматической публикации. Для первого запуска с
телефона проще выбрать **GitHub Pages**: сервер и Cloudflare не нужны.

1. Распакуйте архив и загрузите **всё содержимое папки проекта** в пустой
   GitHub-репозиторий. Важно сохранить папку `.github`.
2. Откройте репозиторий в браузере телефона:
   `Settings` → `Pages` → `Source` → **GitHub Actions**.
3. Откройте `Actions` → **1 — Опубликовать GitHub Pages** → `Run workflow`.
   При загрузке файлов сразу в ветку `main` процесс также запустится сам.
4. После зелёной галочки откройте ссылку из шага `deploy` и добавьте сайт на
   главный экран телефона.

Если вкладки `Settings` или `Actions` не видны, включите в браузере
**«Версия для компьютера»**. Команды на телефоне вводить не требуется.

В Pages-версии задачи хранятся в браузере конкретного устройства. Делайте
резервную копию через настройки приложения. Для Telegram, синхронизации между
устройствами, D1 и серверных напоминаний используйте второй workflow:
**2 — Опубликовать полную версию Cloudflare**.

Подробные пошаговые инструкции:
