# Security Policy

## Supported version

Исправления безопасности выпускаются для последней версии ветки `main`.

## Как сообщить об уязвимости

Не создавайте публичный issue с деталями эксплуатации. Используйте GitHub:

`Security` → `Advisories` → `Report a vulnerability`.

Укажите:

- затронутый URL или компонент;
- условия воспроизведения;
- ожидаемое и фактическое поведение;
- минимальный proof of concept без чужих данных;
- возможное влияние.

Не проверяйте уязвимость на данных других пользователей и не выполняйте
деструктивные действия.

## Секреты

Telegram bot token, webhook secret, cron secret и Cloudflare token должны
храниться только в secret manager платформы. При случайной публикации секрет
нужно немедленно отозвать и заменить, даже если commit был удалён.
